# Scripts de Asistencia para Gym Management

Este repositorio contiene scripts para ayudarte a configurar el proyecto.

### Flujo de Trabajo

1.  **Usa `crear-proyecto.bat`:** Ejecuta este script para crear un proyecto Laravel + Jetstream nuevo y limpio en una carpeta llamada `gym-management-system`.
2.  **Usa `subir-a-git.bat`:** Después de crear el proyecto, copia este script DENTRO de la nueva carpeta y ejecútalo para subir el proyecto base a tu repositorio de Git.
3.  **Espera mis cambios:** Una vez que el proyecto base esté en Git, yo empezaré a añadir las funcionalidades del gimnasio.
