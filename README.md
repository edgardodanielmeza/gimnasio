# Scripts de Instalación y Actualización

Este repositorio contiene scripts para facilitar la configuración inicial y las futuras actualizaciones del proyecto Gym Management.

## `crear-proyecto.bat`

Este script crea un proyecto de Laravel completamente nuevo con todas las dependencias necesarias (Jetstream, Livewire, etc.). **Úsalo solo una vez para crear la base del proyecto.**

### Instrucciones
1. Coloca este script en el directorio donde quieres que se cree el proyecto (ej. `c:\wamp64\www`).
2. Ejecútalo haciendo doble clic o desde una terminal.
3. Sigue las instrucciones en pantalla.

## `actualizar.bat`

Una vez que el proyecto esté creado y sea un repositorio de Git, coloca este script **dentro de la carpeta del proyecto** (ej. `c:\wamp64\www\gym-management-system`).

Ejecútalo cada vez que yo te avise que he subido nuevas funcionalidades. Este script descargará mis cambios de forma segura sin sobreescribir tu configuración local.
